## נתוני הדוגמה (בשביל `seed.js`)

**כללים לכל ההזמנות:** `stage: 'collected'` (רק הן נכנסות לתחנה: `firebase-db.js:1117`). `orderNum` ו־`refNum` זהים. `orderClient` ו־`client` הם שם הלקוח. `clientPhone` ו־`phone` בספרות בלבד. `hasSketch: true`, והתמונה נשמרת ב־`sketches/<id>` ולא בתוך ההזמנה, כמו בייצור אחרי שלב 4. `hashavshevet: { reference, httpOk: true, sentAt }`, כדי שתוצג האסמכתא (`firebase-db.js:1339-1343`, `toReference` ב־`api/hashavshevet-order.js:83`: "L9301" ← "9301"). `date` בפורמט he-IL, למשל `"08.10.2026"`. `pricesLockedAt` ו־`lockedItems` עם `pricePerM2` הם ערכי דמה. הם לא מוצגים בתחנה, אבל בזכותם עריכת מידה מחשבת מחיר מחדש כמו בייצור (`firebase-db.js:1275-1280`).
