# התקנת הסקריפט של תיבת Orderluz

הסקריפט בודק את התיבה כל דקה ושולח למערכת את המיילים שמגיעים אליה (גם מיילים בלי קבצים — המערכת פשוט מסמנת אותם כמטופלים).
את הערכים ל-ENDPOINT ול-TOKEN מקבלים ממני — לא ממציאים אותם.

## התקנה

1. נכנסים ל-Gmail ומתחברים כ-Orderluz@gmail.com.
2. בלשונית חדשה פותחים script.google.com (באותו חשבון).
3. לוחצים **New project**.
4. מוחקים את כל הקוד שכבר כתוב בחלון.
5. קובץ הסקריפט יישלח אליך ממני (Claude) בצ'אט. פותחים אותו, בוחרים הכל ומעתיקים.
6. מדביקים בחלון, ולוחצים על סמל הדיסקט (**Save**).
7. בתפריט הצד לוחצים על גלגל השיניים (**Project Settings**).
8. יורדים למטה עד **Script Properties** ולוחצים **Add script property**.
9. מוסיפים את ההגדרות האלה, אחת אחת (שם משמאל, ערך מימין):
   - `ENDPOINT` — הכתובת שקיבלת ממני.
   - `TOKEN` — הסוד שקיבלת ממני.
   - `START_AT` — התאריך שממנו מתחילים לקלוט, למשל `2026-10-21T00:00:00Z`. מיילים ישנים יותר לא ייקלטו.
   - `ALLOWED_SENDERS` — כתובות של לקוחות מותרים, מופרדות בפסיק. אם משאירים ריק, כולם מותרים.
10. לוחצים **Save script properties**.

## הרצה ראשונה ואישור הרשאות

1. חוזרים לתפריט הצד ולוחצים על **Editor** (סמל הסוגריים).
2. למעלה, ברשימה ליד כפתור **Run**, בוחרים `emRun`.
3. לוחצים **Run**.
4. יופיע חלון **Authorization required**. לוחצים **Review permissions**.
5. בוחרים את החשבון Orderluz.
6. אם מופיע "Google hasn't verified this app", לוחצים **Advanced** ואז **Go to ... (unsafe)**. זה הסקריפט שלנו, אפשר.
7. לוחצים **Allow**.
8. מחכים שההרצה תסתיים. למטה יופיע **Execution completed**.

## הפעלה כל דקה

1. בתפריט הצד לוחצים על שעון המעורר (**Triggers**).
2. לוחצים **Add Trigger** (למטה בצד ימין).
3. ב-**Choose which function to run** בוחרים `emRun`.
4. ב-**Select event source** בוחרים **Time-driven**.
5. ב-**Select type of time based trigger** בוחרים **Minutes timer**.
6. ב-**Select minute interval** בוחרים **Every minute**.
7. לוחצים **Save**.

מעכשיו הסקריפט עובד לבד. במיילים שנקלטו תופיע תווית `LG/נקלט`, ובמיילים שנכשלו תופיע `LG/נכשל`.

## איך עוצרים

1. נכנסים שוב ל-script.google.com ופותחים את הפרויקט.
2. לוחצים על **Triggers**.
3. ליד השורה של `emRun` לוחצים על שלוש הנקודות ואז **Delete trigger**.

כשהטריגר נמחק, שום דבר לא נשלח יותר. אפשר להוסיף אותו שוב בכל רגע.

## אם משהו לא עובד

- נכנסים ל-**Executions** בתפריט הצד ורואים אם הייתה שגיאה.
- שגיאת הרשאה (401 או 403) — כנראה ה-TOKEN שגוי. פנה אליי.
- מייל שקיבל `LG/נכשל` לא ייבדק שוב אוטומטית. מטפלים בו ידנית כמו עד היום, או מבקשים מהלקוח לשלוח אותו שוב.
