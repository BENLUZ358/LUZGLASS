# מרכז הדפסות + מדבקות מחיסום — אפיון (בן, 3/11)

## למה
יש לקוחות שמבקשים מדבקה על כל זכוכית עם שם, מידה ושם סקיצה, כדי לחלק את
הזכוכיות לפי הזמנות אצלם. היום אין דרך להדפיס את זה. בן קנה מדפסת מדבקות
TSC TE210 ברשת. בהמשך גם דוח החיסום יודפס במדפסת הרגילה — ולכן זה נבנה
כ**מרכז הדפסות** כללי, והמדבקות הן הסוג הראשון.

## מי ואיפה
- מי שבודק את החיסום מסמן "הגיע" **באייפד** (workday.html, טאב חיסום),
  ומדביק את המדבקות.
- המחשב במשרד דולק תמיד ומריץ את כלי החשבוניות (`tools/invoice-watcher`,
  מותקן ב-`C:\LuzGlass\invoice-watcher`). הוא המתווך: דפדפן באייפד לא יכול
  לדבר ישירות עם מדפסת ברשת הפנימית, ו-TE210 לא תומכת ב-AirPrint.
- מדפסת המדבקות: TSC TE210, `10.0.0.253`, פורט 9100 (TSPL), 203dpi.
  מדבקה 70×70 מ"מ (≈ 559×559 נקודות).

## מה בן רואה
1. **בטאב חיסום**, בשורת כל לקוח (ליד "12/15 הגיעו" ו"✓ סמן הכל",
   `workday.html` ~2533): כפתור **"🏷 מדבקות"**.
2. **חלון מדבקות**: מדבקה לכל זכוכית **שמסומנת שהגיעה** אצל הלקוח הזה בדוח
   הזה (`_markedIdxSet`) — כולל מה שסומן ועוד לא נסגר. מה שלא הגיע — לא
   מופיע. זכוכיות זהות (×3) = 3 מדבקות.
   - כל מדבקה בתצוגה מקדימה בצורה שתודפס (ריבוע):
     - **כותרת גדולה:** שם הלקוח (העסק — `orderClient`, למשל "המקום לאמבט")
     - **באמצע, הכי גדול:** המידה, רוחב × גובה במ"מ (`lgDimsText`)
     - **למטה:** שם הסקיצה (`sketchName`, למשל "אסף")
     - **קטן בפינה:** מספר ההזמנה (L1200)
   - **עריכה:** כל שדה במדבקה ניתן לעריכה לפני הדפסה; אפשר להוריד מדבקה,
     ולהוסיף עותק של מדבקה. שינוי בעריכה לא משנה את ההזמנה.
   - כפתור **"הדפס N מדבקות"**.
3. **אחרי הלחיצה**: החלון מראה מצב — "בתור" → "הודפס" / "נכשל: <סיבה>".
   מחשב כבוי → נשאר "בתור" ויודפס כשיחזור.
4. **לוח בקרה של הדפסות** — דף חדש (`prints.html`, קישור מהתפריט ומהחלון):
   - כל ההדפסות, החדשה למעלה: מתי, מי, סוג (מדבקות), לקוח, כמה, מדפסת, מצב.
   - פתיחת הדפסה → רואים את המדבקות שלה, אפשר לערוך, ו**"הדפס שוב"**
     (הכל או מדבקות נבחרות). הדפסה חוזרת = הדפסה חדשה ברשימה.
   - מצב המדפסות: מתי המחשב במשרד דיבר עם השרת לאחרונה (כדי לדעת שהוא דולק).
   - סינון לפי לקוח/תאריך. שמירה: 90 יום (ההחלטה שלי — בן יכול לשנות).

## איך זה עובד מתחת
- **עבודת הדפסה** = רשומה עם: סוג (`labels`), לקוח, מספרי הזמנות, רשימת
  מדבקות **כטקסט** (title, dims, sketch, orderNum), מדפסת יעד, מצב
  (`queued` / `printing` / `printed` / `failed`), מי ומתי, ניסיונות, שגיאה.
- **הציור**: הדפדפן מצייר כל מדבקה על canvas בגודל 559×559 (שחור-לבן,
  גופן Heebo שכבר קיים באתר) — **אותו ציור** משמש לתצוגה המקדימה ולהדפסה,
  כך שמה שרואים זה מה שיוצא. עברית — רק כתמונה (אין גופן עברי במדפסת).
  התמונות נשלחות עם העבודה; הדפסה חוזרת מציירת מחדש מהטקסט השמור.
- **אחסון**: תחת `waMeta/printJobs` דרך API (כמו "חשבוניות לפרטי") —
  **בלי שינוי חוקים** (`database.rules.json` לא נוגעים). הדפדפן לא כותב ישירות.
  API: יצירה, רשימה, קריאה — אדמין; משיכה+דיווח — טוקן הכלי במחשב (כמו
  העלאת החשבוניות). ⚠️ מגבלת 12 פונקציות ב-Vercel: דרך rewrite לפונקציה
  קיימת, כמו `/api/invoice-ctl`.
- **הכלי במחשב**: לולאה קיימת של כלי החשבוניות מוסיפה כל כמה שניות: משיכת
  עבודה בתור (נעילה כדי שלא תודפס פעמיים), המרת התמונות ל-TSPL
  (`SIZE 70 mm,70 mm` / `GAP` / `CLS` / `BITMAP` / `PRINT 1`), שליחה ב-TCP
  ל-`10.0.0.253:9100`, דיווח הודפס/נכשל. הגדרות ב-`config.json`
  (`labelPrinter: {host, port}`), כמו `printCopyTo`.
- **בטיחות הדפסה כפולה**: עבודה נמשכת עם נעילה + זמן תפוגה; "printing" שנתקע
  חוזר לתור רק אחרי תפוגה; דיווח "הודפס" אחרי שהשליחה ל-9100 נסגרה בהצלחה.
  (TCP הצליח ≠ נייר יצא — זה הגבול; מצב "נכשל" לחיבור שנכשל.)

## מטרות / לא-מטרות
- מטרה: לחיצה באייפד → מדבקות על המדפסת תוך שניות; היסטוריה והדפסה חוזרת.
- לא עכשיו: דוח החיסום במדפסת הרגילה (רק להשאיר מקום לסוג `report`);
  ברקוד; שבלונות מרובות; הדפסה מהטלפון כאפליקציה.
- אנטי-מטרה: מדבקה לזכוכית שלא הגיעה; הדפסה כפולה אוטומטית; שינוי בהזמנה
  מתוך העריכה.

## הכרעות אחרי בדיקת בונה (שלי, 3/11)
1. **התמונות:** הדפדפן שולח לכל מדבקה מפת ביטים ארוזה (1 ביט לנקודה, שורות של
   70 בתים, base64) — הכלי במחשב לא צריך ספריית תמונות. נשמרות בצומת נפרד
   (`waMeta/printJobBlobs/<id>`) ונמחקות כשהעבודה הודפסה או נכשלה. ברשומה
   עצמה — רק הטקסט; פתיחה מהלוח והדפסה חוזרת מציירות מחדש מהטקסט.
2. **נייר:** ברירת מחדל `GAP 3 mm,0` (מדבקות עם רווח); כיול מול הדפסת ניסיון
   ראשונה במדפסת האמיתית. רוחב התמונה 560 נקודות (70 בתים).
3. **הרשאות:** workday.html נכנס כאדמין (`lgRequireAuthAsync('admin')`) —
   יצירה/רשימה עם `_lgAuthPost` כמו היום. מי הדפיס = שם המשתמש מהסשן.
4. **הכלי במחשב:** אותו טוקן כמו העלאת החשבוניות (`INVOICE_UPLOAD_TOKEN`, כבר
   ב-config.json וב-Vercel) — בלי משתנה חדש. כל משיכה (גם כשאין עבודות) מעדכנת
   `waMeta/printAgent/lastSeenAt`.
5. **מדבקה = רשומה אחת** ברשימה (×3 = 3 רשומות). "הוסף עותק" מוסיף רשומה.
6. **הדפסה כפולה:** נעילה של 2 דקות. אין ניסיון חוזר אוטומטי אחרי ששליחה
   התחילה: עבודה שנתקעה ב-"printing" מסומנת "לא ידוע — בדוק את המדפסת", ובן
   מחליט אם ללחוץ "הדפס שוב". חיבור שנכשל לפני השליחה (מדפסת כבויה) — חוזר
   לתור, עד 3 ניסיונות, ואז "נכשל".
7. **תפריט + שמירה:** קישור "🖨 הדפסות" בתפריט הצדדי של כל הדפים שיש בהם
   (`unav-nav`). מחיקה אחרי 90 יום — בזמן יצירת עבודה חדשה (בלי cron).
8. **טריפלקס:** `_markedIdxSet(sid, track)` כבר לפי מסלול — אותו כפתור באותה
   שורה בשני הטאבים.

- כיול כיוון/היסט מול המדפסת בפועל (DIRECTION/REFERENCE) — אחרי הדפסת ניסיון.
