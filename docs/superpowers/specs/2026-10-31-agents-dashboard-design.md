היום כל מה שקשור אליהם מפוזר: לשונית "סוכנים · ניסיון" בתוך קליטות, "ביטולים מהסוכן" בתיקון הזמנות,

בן רוצה מקום אחד, מקצועי, שבו רואים: מה הסוכנים עשו, מה חריג ודורש טיפול, ומספרים.

  עם מונה "דורש טיפול" כמו `navHsCorr`.
- הגישה: כמו שאר דפי האדמין (משתמש Firebase מחובר עם הרשאת אדמין). קריאה ישירה מ-`waMeta/*` בדפדפן (כבר מותר —

  בקליטות נשארות רק לשוניות WhatsApp ומייל. "ביטולים מהסוכן" נשאר גם בתיקון הזמנות (שם מבצעים אותו),
  והדף החדש מפנה לשם.

## מה בדף, מלמעלה למטה

### 1. דורש טיפול (מוצג רק כשיש משהו)
כרטיס לכל אחד מאלה, החדש למעלה:
| חריג | מקור | מתי מופיע | פעולה |
|---|---|---|---|
| הצעת מחיר מחכה לשאול | `waMeta/agentQuotes` state `waiting`/`relaying` | תמיד; אדום מעל 3 שעות (כמו `STUCK_MS`) | "טופל" |
| ביטול שמחכה לחשבשבת | `waMeta/agentCancels` confirmed && hsSent && !done | תמיד | קישור "לתיקון הזמנות" |
| הודעה שלא נשלחה | `waMeta/agentOutbox` state `blocked`/`failed`, 7 ימים אחרונים | | "טופל" |
| רשומה שנכשלה בעיבוד | `waMeta/agentShadow` state `failed`/`dead` | | "טופל" |
| הסוכן לא הבין | `agentShadow` intent `unclear` מלקוח מקושר, 7 ימים | | "טופל" |
| סומן ✗ | `agentShadow` verdict.ok === false, 7 ימים | | "טופל" |

- "טופל" = הסתרה מהרשימה בלבד (לא משנה את הרשומה עצמה). נשמר ב-`waMeta/agentDash/dismissed/<kind>_<key>` =
  `{at, by}` דרך פעולה חדשה `agent-dismiss` ב-drain. הסתרה מכסה רק את הכרטיס הזה, לא חריגים חדשים.
- "פתח בוואטסאפ" (`https://wa.me/972…`) מופיע רק כשיש מספר פרטי של לקוח (`sender` / `linkVia:'sender'`).
  לקבוצה אין קישור ישיר — לא מציגים כפתור.
- מונה החריגים (שלא הוסתרו) מוצג גם בתפריט של admin.

### 2. מספרים
בורר: **היום / 7 ימים / 30 יום** (היום = מחצות שעון ישראל). אותן הגדרות כמו `lgAgentDailySummary`, כדי שהלוח
והסיכום היומי לא יסתרו זה את זה:
- הודעות שנכנסו (בלי הודעות צוות), נסגרו לבד, הועברו לשאול, הצעות מחיר (נוצרו בתקופה), ביטולים (בתקופה),
  ממספרים לא מקושרים.
- **דיוק הסוכן**: ✓ / (✓+✗) באחוזים + "עוד לא סומנו: N".
- פילוח לפי סוכן (route): כמה הודעות הגיעו לכל אחד — שורה קטנה של מספרים, בלי גרפים בשלב זה.
- כשהסוכנים במצב שקט: "נסגרו לבד" = "היה סוגר לבד" (כותרת מתחלפת לפי מצב).

### 3. יומן עבודה
- כל רשומת `agentShadow`, החדשה למעלה, 30 יום אחרונים, עם "הצג עוד" (50 בכל פעם).
- שורה: לקוח (או "לא מקושר"), זמן, מה נכתב, כוונה ← סוכן, מה נעשה / היה נעשה (כולל מצב תור השליחה), ✓/✗.
  זה בדיוק התוכן של `lgAgRowHtml` היום — מעבירים את הלוגיקה, לא ממציאים חדשה.
- סינון: לפי סוכן, לפי לקוח (חיפוש בשם), לפי סימון (הכל / לא סומן / ✓ / ✗).

### 4. מצב הסוכנים
- מצב כללי אחד (המתגים משותפים לכל הסוכנים): **כבוי / מצב שקט / עונה ללקוחות בפיילוט**, לפי משתני הסביבה.
  הדפדפן לא רואה משתני סביבה → פעולה חדשה `agent-status` ב-drain שמחזירה **בוליאנים בלבד**:
  shadow, reply, model מוגדר, מפתח OpenAI מוגדר, צוות מוגדר, סיכום מוגדר, CRON_SECRET מוגדר. אף ערך לא חוזר.
  חסר משהו → שורה אדומה בעברית פשוטה ("אין מפתח OpenAI — הסוכנים לא מבינים הודעות").
- רשימת ששת הסוכנים עם משפט אחד מה כל אחד עושה, ומונה הודעות 7 ימים.
- לקוחות בפיילוט: רשימה עם "הוצא מפיילוט"; "הוסף לפיילוט" עם בחירה מתוך לקוחות מקושרים בלבד
  (`waGroups` / `waSenders` עם customerId) — אותו כלל כמו היום. פעולה קיימת `agent-pilot`.

## לא בשלב הזה (non-goals)
- גרפים, ייצוא, התראות push, מחיקת רשומות, שינוי משתני סביבה מהדף, עריכת תשובות הסוכן.
- שמירת היסטוריה (retention) — החלטה נפרדת.
- התיקון של הסיכום היומי במצב שקט — הלוח מחליף אותו בינתיים.

## אסור שיקרה (anti-goals)
- שום כתיבה ל-Firebase מהדפדפן; שום שינוי חוקים.
- שום ערך של משתנה סביבה חוזר לדפדפן.
- טקסט של לקוח מוצג רק ממה שכבר נשמר (מספר לא מקושר נשמר בלי טקסט — נשאר כך).
- הדף לא שובר את קליטות: אחרי ההעברה WhatsApp/מייל עובדים בדיוק כמו קודם.

## הבהרות אחרי בדיקת בונה (Claude)
- **מספרים**: "היום" = מחצות שעון ישראל, לא 24 שעות מתגלגלות. הצעות מחיר וביטולים בכרטיס המספרים = שנוצרו
  בתקופה; "מחכים עכשיו" מופיע בדורש טיפול. ההגדרות של נכנסו / נסגרו לבד / לשאול / לא מקושרים / ✗ — כמו
  `lgAgentDailySummary`. `_agent-daily.js` לא משתנה, ואין בדיקת שוויון מספרים מולו (התקופות שונות).
- **"טופל" ונחזר**: ההסתרה שומרת גם את `updatedAt` (או `at`) של הרשומה ברגע הלחיצה. אם הרשומה השתנתה אחרי
  זה — הכרטיס חוזר. פריט שלא השתנה נשאר מוסתר לתמיד.
- **רשומת צל שנכשלה**: חריג רק כשהיא `dead`, או `failed` עם attempts ≥ 3. פחות מזה המערכת עוד מנסה לבד.
- **המונה בתפריט admin**: קריאה חד-פעמית (`once`) בטעינת admin של agentQuotes / agentCancels / agentOutbox /
  agentDash, ושל agentShadow מ-7 הימים האחרונים בלבד (`orderByChild('createdAt').startAt`). בלי מאזין חי. ההיקף
  היום עשרות רשומות; שמירת היסטוריה נשארת החלטה נפרדת.
- **שאול**: קריאת waMeta מותרת רק לאדמין. אם שאול לא אדמין — ראה שאלה פתוחה לבן.
