# invoice-watcher (DB-00004)

כלי למחשב המשרד. עוקב אחרי תיקיית הפלט של מדפסת PDF; חשבונית שמודפסת אליה
(עמוד 1 = מקור, עמוד 2 = העתק) מועלית לשרת, וההעתק נשמר בתיקייה השיתופית
בתבנית `שנה/חודש/לקוח/תאריך_מספר.pdf`.

## התקנה
1. התקנת מדפסת PDF (למשל "Microsoft Print to PDF" עם תיקיית פלט קבועה, או מדפסת וירטואלית אחרת)
   והדפסת חשבוניות בחשבשבת אליה במקום למדפסת הרגילה.
2. `npm install` בתיקייה זו.
3. `config.json` (לא להעלות ל-git):
```json
{
  "watchDir":   "C:\\InvoicePrints",
  "sharedRoot": "\\\\SERVER\\Share\\חשבוניות",
  "url":        "https://<האתר>/api/invoice-pdf-upload",
  "token":      "<INVOICE_UPLOAD_TOKEN מ-Vercel>"
}
```
4. `node watcher.js`

## תיקיות
- `done/` — עובד והועתק לארכיון.
- `review/` — השרת סירב (לא זוהה מקור/העתק או שיוך). לא נשלח ללקוח; לטיפול ידני.
- `pending-copy/` — התיקייה השיתופית לא הייתה זמינה; הקובץ המקורי נשאר ויעובד בסבב הבא.

## הדפסה לפני "החשבונית הופקה"
אם ההדפסה מגיעה לפני שרשמת את מספר המסמך בתחנת החשבוניות, השרת שומר אותה (תשובה 202 `held`)
והכלי משאיר את הקובץ ומנסה שוב כל דקה (`holdRetryMs` ב-config). מרגע שנרשם המספר, הניסיון הבא מקבל נתיב ארכיון וההעתק נכתב.
